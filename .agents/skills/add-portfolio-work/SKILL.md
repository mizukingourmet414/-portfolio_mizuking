# ポートフォリオに作品を1件追加する

1. 編集前に、ユーザーに作品名・説明・公開用URLをまとめて聞く。すでに受け取った項目は再利用し、不足している項目だけ尋ねる。3項目が揃ってから編集する。URLはHTTPまたはHTTPSを使う。
2. リポジトリルートの `AGENTS.md` と `デザイン.md` を読み、`dist/index.html` の「作ったもの」に既存と同じ構造でカードを1件追加する。カバー、カテゴリ、作品名、説明の順に並べ、作品名を指定URLへのリンクにする。画像の指定がなければ既存のカバー表現に合わせて作品名を使う。カテゴリは説明に合わせる。入力はHTMLのテキストと属性に応じてエスケープする。
3. 差分で追加が1件であることを確かめる。PC幅とスマホ幅の表示、作品リンクの行き先、キーボードフォーカスを確認する。
4. Gitの状態、現在のリモートの所有者と公開ブランチを確認する。移管や履歴の分岐があればリモートの公開ブランチを起点とした作業コピーなどを使い、双方の変更を保つ。作品追加に必要なファイルだけを「作品『作品名』を追加」などのメッセージでコミットし、公開ブランチへプッシュする。直接プッシュが制限される場合は作業ブランチへプッシュし、公開に必要な手順を伝える。
5. プッシュ先にコミットが反映されたことを確認し、作品名とコミットへのリンクを報告する。プッシュできなければ、保存したコミットと具体的な理由を伝える。実施できなかった確認があれば併記する。
